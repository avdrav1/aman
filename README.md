# Aman

A browser prototype of a turn-based strategy game about reuniting the Indian subcontinent by consent in 2050.

You lead the Deccan Compact. Fifteen rival powers share the subcontinent. Bring eight into a federation within sixteen seasons, hold eleven through Act 2, and win eleven pledges to ratify a charter, while a private arms conglomerate called the Company works to keep them apart.

## Play

```bash
python3 -m http.server 8000 -d public
```

Open http://localhost:8000. There is no build step. Opening `public/index.html` directly also works.

## Develop

```bash
node tools/sim.js             # balance check across 2,000 simulated games per bot
python3 tools/smoke_test.py   # browser smoke test; needs Playwright
python3 tools/build_map.py --write   # rebuild the map from Natural Earth data
```

- `public/engine.js` holds every rule and has no DOM.
- `public/index.html` holds the interface. Its map block is generated by `tools/build_map.py`.
- `CLAUDE.md` is the project brief for Claude Code. Start there.
- `docs/` has the design, the rules as implemented, and the backlog.

## Deploy

Two static files in `public/`. Any static host works: set the output directory to `public` with no build command. Nothing outside `public/` is served.

## Status

A prototype of the diplomacy layer only. Battles are auto-resolved. Names, numbers, and art are placeholders, and the content has not been reviewed by people from the region it depicts.
